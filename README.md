# SupernormalCo/agent-plugins

Supernormal for Claude, Cursor and other AI agents: your Rooms' wiki, documents, databases, chat, tasks and connected apps.

- `plugins/claude/supernormal`: connects to `https://rooms.supernormal.com/mcp`
- `plugins/cursor/supernormal`: connects to `https://rooms.supernormal.com/mcp`
- `plugins/agent-plugins/supernormal`: connects to `https://rooms.supernormal.com/mcp`

Install in Claude Code:

```
/plugin marketplace add SupernormalCo/agent-plugins
/plugin install supernormal@supernormal
```

Generated by `integrations/agents/scripts/build.mjs --publish` in SupernormalCo/supermono
and pushed by its Publish agent plugins workflow. Do not edit by hand; changes here are
overwritten on the next publish.
